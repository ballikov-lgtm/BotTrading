# ignored. Folder paths (e.g. SID/pine) pull the whole folder.

# the denylist in .github/workflows/sid-update.yml — if one ever appears here or in
# a staged diff, the one-click updater ABORTS.

# Both the guided prompt (SID-UPDATE-PROMPT.md) and the one-click updater
# (.github/workflows/sid-update.yml) read THIS file, so the list lives in exactly
